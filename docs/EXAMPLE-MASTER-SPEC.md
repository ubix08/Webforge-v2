## 1. Executive Summary

**What it is:** A business task and project management tool for small teams
**Who uses it:** Managers who track projects, team members who complete tasks
**Core value:** Replace scattered spreadsheet tracking with a single organized workspace
**Tech target:** React 18 + TypeScript + Vite + Tailwind + shadcn/ui

---

## 2. User Personas

### Persona 1: Team Manager
- **Role:** Project manager / team lead
- **Goals:** See all project status, assign tasks, track deadlines
- **Pain Points:** Status updates scattered across email, Slack, spreadsheets
- **Usage:** Daily, multiple times per day

### Persona 2: Team Member
- **Role:** Individual contributor
- **Goals:** Know what to work on, update task status quickly
- **Pain Points:** Not knowing priorities, too many status update meetings
- **Usage:** Daily, starting each morning

---

## 3. User Stories (v1 Scope)

### Authentication
- [ ] As a user, I can register with name, email, and password
- [ ] As a user, I can log in and remain logged in for 7 days
- [ ] As a user, I can log out from any page

### Projects
- [ ] As a manager, I can create a project with name, description, and due date
- [ ] As a user, I can view all projects I have access to
- [ ] As a manager, I can edit or archive a project
- [ ] As a user, I can view a project's task board

### Tasks
- [ ] As a manager, I can create a task within a project
- [ ] As a manager, I can assign a task to a team member
- [ ] As a user, I can update a task's status (todo → in-progress → done)
- [ ] As a manager, I can set task priority (low / medium / high)
- [ ] As a user, I can add comments to a task
- [ ] As a manager, I can delete a task

### Dashboard
- [ ] As a user, I see my assigned tasks across all projects on the dashboard
- [ ] As a manager, I see a project completion overview

## 4. Feature Inventory

### ✅ v1 CORE

#### Feature: Authentication
- **UI:** Login page, Register page, ProtectedRoute wrapper
- **Components:** `LoginForm`, `RegisterForm`, `AuthLayout`
- **State:** `authStore` (Zustand persist)
- **API:** POST /auth/register, POST /auth/login, DELETE /auth/logout

#### Feature: Projects
- **UI:** Projects list page, Project detail page (tabbed)
- **Components:** `ProjectCard`, `ProjectForm`, `ProjectDialog`, `ProjectTable`, `ProjectEmpty`
- **State:** `projectStore` (UI state)
- **API:** GET/POST /projects, GET/PUT/DELETE /projects/:id

#### Feature: Tasks
- **UI:** Task board within project, Task detail dialog
- **Components:** `TaskCard`, `TaskForm`, `TaskDialog`, `TaskBoard`, `TaskStatusBadge`
- **State:** `taskStore` (UI state)
- **API:** GET/POST /projects/:id/tasks, GET/PUT/DELETE /tasks/:id

#### Feature: Dashboard
- **UI:** Overview page with widgets
- **Components:** `StatsCard`, `MyTasksList`, `ProjectProgressList`
- **API:** GET /dashboard/stats, GET /tasks?assignedTo=me

### 🔜 v2 BACKLOG
- Comments per-task
- In-app + email notifications
- Team invite management
- File attachments
- CSV export / burndown charts

## 6. Route Architecture

| Path | Component | Auth | Layout | Description |
|------|-----------|------|--------|-------------|
| `/` | → /dashboard | yes | App | Redirect |
| `/login` | LoginPage | No | Auth | Login form |
| `/register` | RegisterPage | No | Auth | Register form |
| `/dashboard` | DashboardPage | Yes | App | Overview widgets |
| `/projects` | ProjectsPage | Yes | App | All projects list |
| `/projects/new` | NewProjectPage | Yes | App | Create project |
| `/projects/:id` | ProjectDetailPage | Yes | App | Project + tasks |
| `/settings` | SettingsPage | Yes | App | User settings |
| `*` | NotFoundPage | No | Minimal | 404 |
